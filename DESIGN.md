# Visual contract

Modern field journal + outdoor expedition + trail marker + mission card + modern consumer software.

Use warm paper, forest ink, restrained lime trail accents, subtle borders, generous spacing, strong typography and tactile mission cards. Completion is the visual hero: oversized Away Ratio, a trail-style completion stamp, and a compact metric receipt. No external font/image fetches are required to run or build.

Avoid generic SaaS dashboards, chat UI, purple/blue AI gradients, AI sparkles, glassmorphism, huge navigation, data-heavy dashboards, excessive shadows, decorative complexity or complex animation.

## UX
Mobile first, one dominant action per screen, large touch targets (at least 44px), minimal reading, high contrast, visible keyboard focus. Interface disappears quickly. Primary viewport approximately 390×844; support 375px, 430px and desktop with a centered reading width. Content may scroll on smaller screens; never hide the primary action behind fixed overlays.

## Five screens
Landing: short promise and Start a SideQuest.
Setup: exactly three duration choices, four moods and three environments.
Quest: 2–3 readable mission cards; Begin switches to quiet active state with I'm back.
Evidence: one local preview with replace/remove controls; explicit checking, verified, uncertain and provider-error states; self-report remaining tasks. Uncertain and error states allow completion without counting the photo discovery.
Completion: mission complete, demo estimate and discoveries, honest photo verification receipt, restart action.

Use text labels alongside decorative symbols. Completion timing keeps a visible demo label. Evidence verification is real and must not carry a mock label. No real XP economy; optional demo XP must never imply a retention system.
